-Deployment: The technical process of releasing a software application, website, or system update to a live environment so that it is fully accessible and usable by end-users.
-PO (Product Owner): A core role within the Scrum framework responsible for refining product requirements and managing the prioritized list of features in the Product Backlog.
-Scrum: An Agile project management methodology that delivers value through short, iterative cycles called sprints. It is governed by three fundamental pillars: transparency, inspection, and adaptation.
-Semantic Tags: HTML markup elements (such as <article>, <nav>, or <h1-h3>) that convey the structural meaning and hierarchy of the content to browsers and search engines, which is essential for proper on-page SEO.
-Backlog:

  -Product Backlog: A prioritized master list containing all the needs, features, and work required to build or improve a product
 -Sprint Backlog: The specific items and detailed tasks selected by the team to be completed during the current sprint.
-Epics: Large, high-level bodies of work or project visions that are too substantial to be completed in a single iteration and must be broken down into smaller, actionable user stories.
-User Stories: Brief, informal descriptions of a product feature written from the perspective of the end user, which the Agile team estimates and breaks down into specific tasks during sprint planning.
-Persona: A fictional character constructed using real data from user research that highlights specific user goals, traits, and frustrations to guide user-centric design decisions.
-Wireframe: The static, uncolored visual skeleton of a digital product, used primarily to position layout blocks, text, and placeholders to test the structure.
-Prototype: An interactive model created by linking wireframes or screens together, allowing designers to test the clickability and flow of the user journey.
-Mockup: The final, high-fidelity visual design that applies all aesthetic UI choices, including definitive colors, images, and typography.
-WCAG (Web Content Accessibility Guidelines): W3C standards built on making content perceivable, operable, understandable, and robust so that the web is accessible to everyone, including individuals with disabilities.
